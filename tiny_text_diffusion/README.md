# Tiny Text-Conditioned Diffusion

An educational implementation of conditional diffusion from scratch,
starting with a synthetic image-caption dataset.

## Planned components

- Reproducible synthetic image-caption dataset
- Text encoder
- Conditional U-Net
- Forward diffusion and noise prediction
- Reverse diffusion sampling
- Prompt adherence evaluation

## Environment

Designed for experimentation with Google Colab GPUs.

## Current status

Project setup in progress. Model implementation has not started.
